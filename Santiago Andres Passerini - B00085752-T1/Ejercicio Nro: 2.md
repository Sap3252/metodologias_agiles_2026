# Ejercicio Nro: 2

## Enunciado
1. Ejemplos de desarrollo de software en los que hayas participado? Ejemplos que conozcas?
2. Cual es el papel del desarrollador en el desarrollo de un proyecto de software?
3. Hay otrs papeles importantes en el desarrollo, aparete del desarrollador?
4. Cuando se ha desarrollado un buen software?

## Resolución
1. Yo mismo he participado de algunos desarrollos de software que fueron partes de trabajos academicos para la aprobacion de materias. He hecho sistemas de gestion empresarial, sistemas de compras de entradas para cine entre otros.

2. El papel que cumple un desarrollador en quien con informacion suministrada es quien construlle el sistema.

3. Si, hay otros papeles importantes como el que consigue la informacion para el desarrollador osea un ingeniero de requerimientos que se encarga de a traves de reuniones y comunicaion con los usuarios es capaz de saber que necesita el sistem para cumplir con los requerimientos.

4. Yo creo que un software se considera un buen software cuando cumple con los requisitos pedidos por el cliente, es eficiente y esta bie diseñado.
