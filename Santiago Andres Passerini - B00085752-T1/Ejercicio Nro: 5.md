# Ejercicio Nro: 5

## Enunciado
Proponga cinco elementos que ayuden en el desarrollo de software referido a la propiedad de flexibilidad que se requiere.

## Resolución
1. Patrones de Diseño: Emplea estrategias validadas para inconvenientes habituales; están ideados justamente para dotar al código de adaptabilidad frente a nuevas exigencias
2. Pruebas (Testing): Disponer de personal de evaluación facilita la implementación de modificaciones; lo óptimo es que el código sea adaptable para alterarse, y los tests otorgan respaldo al garantizar que no se pierda calidad
3. Interfaces: Programar guiándose por interfaces en lugar de implementaciones específicas habilita, por ejemplo, la sustitución de una base de datos sin alterar la lógica de negocio central. Requieren saber usarlas, pero son valiosas y previenen inconvenientes
4. Diseño Modular: Fraccionar el sistema en componentes reducidos y autónomos (módulos) permite que, al alterar la lógica de un sector, no se perjudique al resto, simplificando mucho su mantenimiento
5. Acoplamiento Reducido y Alta Cohesión: Procurar que los componentes del programa tengan la menor dependencia mutua posible (bajo acoplamiento) y que posean un propósito exclusivo y definido (alta cohesión). Esto previene el "efecto dominó" donde una modificación arruina múltiples elementos en otra parte del sistema
